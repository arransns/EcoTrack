# Security Policy

Security is an important part of the EcoTrack development process.

EcoTrack is currently under active development and the GitHub Pages version is
primarily intended as a public preview.

---

## Supported Versions

The latest publicly available version of EcoTrack is the version currently
maintained and supported.

| Version | Supported |
| ------- | --------- |
| Latest  | Yes       |
| Older versions | Limited |

---

## Reporting a Vulnerability

If you discover a security issue related to EcoTrack, please report it
responsibly.

Do not publicly disclose potentially sensitive security vulnerabilities before
the project owner has had a reasonable opportunity to review the issue.

When reporting a vulnerability, please include:

- A clear description of the issue
- Steps required to reproduce it
- The affected page or feature
- Browser and operating system information when relevant
- Screenshots or supporting information when useful
- The potential security impact

---

## Public Preview

The version hosted through GitHub Pages is a static demonstration and does not
contain the complete EcoTrack authentication, database, or backend
infrastructure.

Features displayed as Coming Soon should not be considered production-ready
services.

---

## Responsible Disclosure

Security researchers, developers, and users are encouraged to report issues
responsibly and avoid:

- Exploiting vulnerabilities beyond what is required for verification
- Accessing data that does not belong to them
- Disrupting the availability of EcoTrack
- Publishing sensitive vulnerability information without prior coordination

---

## Scope

Security reports may include issues related to:

- Client-side JavaScript
- User interface behavior
- Deployment configuration
- Authentication systems when publicly released
- Database or backend integrations when publicly released
