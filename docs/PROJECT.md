# EcoTrack Project

EcoTrack adalah platform environmental technology yang dikembangkan untuk membantu meningkatkan kesadaran masyarakat terhadap pemilahan dan pengelolaan sampah.

## Project Type

Educational and Research Web Project

## Main Focus

- Waste sorting
- Environmental education
- Waste tracking
- Sustainability
- Research
- Interactive technology

## Platform

Web Application

## Current Stage

Active Development / Public Preview

## Public Version

Versi publik EcoTrack tersedia melalui GitHub Pages.

https://arransns.github.io/EcoTrack/

## Main Application

Pengembangan utama EcoTrack menggunakan Laravel dengan sistem backend, database, dan fitur pengguna yang lebih lengkap.
