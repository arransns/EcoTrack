# EcoTrack Roadmap

Roadmap ini menggambarkan arah pengembangan EcoTrack.

## Phase 1 — Public Preview

- Landing page
- Responsive interface
- EcoTrack visual identity
- Motion system
- EcoTrack mascot
- AI Assistant interface
- Dark and Light Theme
- GitHub Pages deployment

Status: Completed

## Phase 2 — Core Platform

- User registration
- User authentication
- User dashboard
- Waste recording
- Waste categories
- Statistics
- User profile

Status: In Development

## Phase 3 — Research System

- Research Mode
- Data collection
- Environmental questionnaire
- Research statistics
- Data visualization

Status: Planned

---

## Phase 4 — Advanced Features

- Improved EcoTrack AI Assistant
- Personalized recommendations
- Advanced statistics
- Community features
- Environmental challenges
- EcoTrack Points

Status: Planned

## Long-Term Goal

Mengembangkan EcoTrack menjadi platform edukasi dan pengelolaan sampah yang mudah digunakan, interaktif, dan bermanfaat untuk masyarakat.
