# EcoTrack

EcoTrack adalah platform digital bertema lingkungan yang dibuat untuk membantu masyarakat memahami, memilah, mencatat, dan memantau pengelolaan sampah dengan cara yang lebih modern dan mudah digunakan.

Website ini dibuat sebagai bagian dari proyek **Karya Tulis Ilmiah Kelas 9 SMP Pembangunan Jaya**.

## Fitur Utama

- Edukasi pemilahan sampah
- Pencatatan sampah
- Statistik dan pemantauan
- Informasi kategori sampah
- Research Mode
- AI Assistant EcoTrack
- Dukungan SDGs
- Dark / Light Theme
- Responsive untuk desktop dan mobile
- Animasi dan interaksi UI/UX

## Teknologi

Website versi publik ini menggunakan:

- HTML
- CSS
- JavaScript
- GitHub Pages

Versi utama EcoTrack dikembangkan menggunakan Laravel.

## Tujuan

EcoTrack dikembangkan untuk membantu meningkatkan kesadaran masyarakat terhadap pentingnya pemilahan sampah dan kebiasaan ramah lingkungan melalui teknologi digital.

EcoTrack juga mendukung beberapa Sustainable Development Goals (SDGs), terutama yang berkaitan dengan pendidikan, lingkungan, kota berkelanjutan, dan konsumsi yang bertanggung jawab.
